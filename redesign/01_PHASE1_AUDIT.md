## 2. Current theming approach

* **Seed theme.** `ColorScheme.fromSeed(seed: #075985 blue, secondary #0F9D94 teal)` with card radius 8 and input radius 8. Nothing else is themed: no text theme, button, nav-bar, dialog, sheet, chip or snackbar themes.
* **Font.** Default Roboto. Material 3's headline letter-spacing makes titles look spaced-out ("G o o d  d a y").
* **Hard-coded styling everywhere.** There are 49 inline `TextStyle(...)`, 25 inline `fontSize`, 117 `Colors.*`, 8 raw hex colors, 83 inline `EdgeInsets` and 10 ad-hoc radii.
* **Mixed icons.** Material `Icons.*`: 90 distinct glyphs in a mix of outlined, filled and rounded styles.
* **No design tokens.** `MedilinkColors` (7 colors) is the only shared token set.
* **Platform shell is default Flutter.** The launcher icon is the stock Flutter logo, the Android splash is plain white, and the app label is lowercase `medilink`. There's no adaptive icon and no Android 12 splash config.

**Implication:** most visual improvement will come from a proper central `ThemeData` plus a handful of shared components. Per-screen edits then mostly swap ad-hoc widgets for those components.

| Type feel | Bold geometric sans for titles, regular for body, comfortable 14–16 sp body | Section 6 below |
| Icons | Outlined, ≈2 px stroke, rounded caps, centered in tinted circles | Chevrons in small outlined circles on tiles |

**Type direction (preliminary, finalized in Phase 3).**

* **UI font:** *Plus Jakarta Sans*. Its proportions and warmth match the reference headings ("Good day", "Health", "Profile") and it has excellent numerals for vitals.
* **Onboarding display font:** *Bricolage Grotesque* (slightly characterful, still calm), with *Fraunces* as a softer alternative. I'll show both in the pilot.

Both are OFL-licensed and will be bundled as asset `.ttf`s, fetched from the `google/fonts` GitHub repo, which your PC's sandbox can reach.

**Icon direction.** Stay on Flutter's built-in Material icon font but standardise on the **rounded/outlined** variants at fixed sizes. That means no new package, works offline, and keeps the capture harness's `find.byIcon` selectors working. A Lucide-style set would match the references slightly more closely but adds a dependency and breaks those selectors. See decision D5.

## 6. Layout and UX defects found (all fixable as presentation)

1. **Action-tile grid is broken on every home** (028, 075, 093, 111). Fixed 112 dp tiles in a `Wrap` give 2 columns plus empty space. → Responsive 2-column grid.
2. **Consent pending row collapses** (044). Name renders one character per line, and the full-width `PrimaryButton` sits inside `ListTile.trailing`, so "Grant" isn't hittable. → Stacked card layout with actions below.
3. **Hospital "Emergency alerts" row collapses** (112, 120). The ID and patient render 1–2 characters per line because wide badges are in `trailing`. → Same fix.
4. **Patient-detail history rows wrap per character** (081, 087, 099, 105, 117). Raw enum plus raw ISO timestamp (`HIGH_RISK · 2026-11-01T09:50:00.000`). → Two-line title/meta layout. Format date and time for display only.
5. **Raw machine strings shown to users.** ISO timestamps ("Last sync: 2026-11-04T09:28:00.000") and enums (`LAB_REPORT`, `PATIENT_SUMMARY`, `TEMPLATE_FALLBACK`). → Display-only formatting helper. The underlying data is untouched.
6. **File names break mid-word** in the Vault (`prescription_cardiology.p / df`). → Ellipsis plus a type chip.
7. **Filtered hospital list shows a blank white card** when empty (113). → Proper empty state.
8. **Duplicate nav icons.** "Connections" and "Command" both fall back to the Home icon (`_icon()` default). → Distinct icons (mapping only; labels and order unchanged).
9. **Tiny nav labels** (11 sp) and a default M3 grey-purple nav background. Dialogs use a purple-tinted M3 surface that clashes with the palette.
10. **Splash** (001): tiny spinner, left-aligned text, no logo. **Welcome** (006): content pinned bottom-left with a large void.
11. **Login/Sign-up**: app-bar title plus "Welcome back" heading duplicate hierarchy. The long sign-up form has no grouping.
12. **Notifications** (030): plain text rows with no icon or structure.
13. **"I'm safe now — end emergency"** (041) is a small pill. Under stress it should be a full-width, clearly secondary button.
14. **Snackbar shows a raw Android path** (061). This is a copy issue; I'll keep the text as-is unless you approve shortening it.
15. **Senior Mode** (1.18× text) already pushes cards. The new layouts must be verified at 1.0×, 1.18× and 1.3×.
